## Reproduce

Run from the AKA checkout with a fresh workspace and the existing gateway authentication:

```bash
python3 orchestrator/optimize.py \
  --op-dir /Users/liangyan/Agent/atrex-bench/data/production_qwen37max_prefill_unici/gdn_qk_l2_norm \
  --platform L20N --sandbox-hardware L20N --arch sm_120 \
  --agent-cli claude --optimization-mode economy \
  --workspace /tmp/aka-economy-l20n --max-iters 2 --max-stall 0 \
  --target-util 0 --token-budget 400000
```

For legacy regression runs, use `--optimization-mode leaderboard --framework Triton
--max-iters 1 --fast-trials 1 --token-budget 1000000`, or
`--optimization-mode production --framework Triton --max-iters 2 --fast-trials 1
--token-budget 1000000`, and separate fresh workspace paths.

The additional Economy V2 accuracy check runs from its generated workspace:

```bash
python3 tools/sandbox.py --kind run --hardware L20N --no-sync -- \
  python test_kernel.py --version v2 --multi-seed 5 --no-memory
```
